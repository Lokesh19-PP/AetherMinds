## Brand & Style

This design system embodies an institutional-grade, dark-luxury aesthetic tailored for zero-trust cryptographic infrastructure, high-throughput financial auditing, and immutable attribution proofs. The visual posture communicates uncompromisable mathematical integrity, high security, and refined executive clarity.

### Target Audience & Emotional Intent
- **Audience:** Cryptographers, protocol engineers, institutional compliance officers, asset custodians, and enterprise IP executives.
- **Emotional Resonance:** Unshakable trust, precision, tactical clarity, and continuous cryptographic verification without friction or sensory fatigue.

### Design Movement & Visual Philosophy
The aesthetic blends **Dark Luxury Minimalism** with **Cyber-Resilient Precision**:
- **Deep Void Surfaces:** Rich, near-abyssal dark tones ground the interface, avoiding pure flat pitch blacks in favor of oceanic cyan undertones (`#000B0F`).
- **Luminescent Telemetry:** Low-diffusion atmospheric halos and vivid edge glows (`#00A8E8`) illuminate active states, validation trees, and cryptographic handshakes.
- **Precision Data Density:** High information fidelity achieved via crisp hairline rules, hairline glassmorphic barriers (`#003459`), and monospaced proof primitives anchored by clean geometric sans-serif structural type.

## Colors

The color system establishes a zero-trust semantic hierarchy. Colors reflect definitive cryptographic states and strictly avoid subjective decoration.

### Core Canvas & Structure
- **Deep Background (`#000B0F`):** Canvas bedrock. Used for system viewports, canvas backdrops, and root shells.
- **Card Surfaces (`#00171F`):** Structural layers, inspection cards, inspector drawers, and data tables.
- **Subtle Glassmorphic Borders (`#003459`):** Outer edge boundaries, structural splitters, and modal borders.
- **Muted Rules (`#D4DEE2` at 12%–18% opacity):** Hairline interior card dividers, table row borders, and inactive boundaries.

### Accents & Interaction
- **Primary Accent (`#007EA7` / Cerulean):** Primary interactive calls-to-action, active segment pills, and system attribution metrics. Attribution metadata must strictly resolve to this cerulean accent—never green.
- **Glow & Links (`#00A8E8` / Electric Sky Blue):** Verified cryptographic beacons, hover glows, focused inputs, hyperlinked transaction hashes, and live telemetry feeds.
- **Secondary Neutral (`#66747A`):** Low-priority labels, inactive states, column descriptors, and placeholder markers.

### Semantic Telemetry
- **Success (`#1E8F53` / Emerald):** Reserved strictly for verified zero-knowledge validity proofs, verified on-chain registrations, and cryptographic signature validations.
- **Danger (`#D93838` / Crimson):** Cryptographic invalidity, checksum mismatch, tamper alerts, revoked credentials, and failed pipeline transactions.
- **Warning (`#DD8E4B` / Amber):** Nonce re-synchronization alerts, pending state confirmations, network fee spikes, and advisory state flags.

## Typography

The system enforces a dual-type family architecture: **Plus Jakarta Sans** guides UI navigation and editorial headings, while **JetBrains Mono** serves as the verifiable mathematical truth tier.

### Role Allocations
- **Plus Jakarta Sans:** High-order headlines, subheads, operational guidance, narrative descriptions, and control interactions.
- **JetBrains Mono:** Mandatory for all cryptographic primitives including cryptographic hashes, SHA-256 digests, Merkle root representations, public key fingerprints, network ports, contract addresses, gas metrics, Unix timestamps, and attribution identifiers.

### Data Rendering Principles
- All numeric telemetry data must utilize tabular figures (`tnum`) to eliminate jitter during real-time streaming updates.
- Monospace strings exceeding spatial constraints must use midpoint truncation (e.g., `0x7F91…41B2`) rather than end truncation to preserve network prefix and checksum tail visibility.

## Layout & Spacing

The structural layout relies on a strict 12-column responsive fluid grid pinned to an 8px base rhythm (with 4px sub-increments for micro-chips, hash badges, and telemetry pills).

### Viewport Breakpoints & Fluid Grid
- **Desktop (≥ 1280px):** 12-column layout, `margin: 2rem` (32px), `gutter: 1.5rem` (24px). Sidebar navigations are fixed at 260px; cryptographic inspection panes use a sticky 380px trailing drawer.
- **Tablet (768px – 1279px):** 8-column layout, `margin: 1.5rem` (24px), `gutter: 1rem` (16px). Trailing drawers fold into contextual bottom sheets or tabbed sub-views.
- **Mobile (≤ 767px):** 4-column layout, `margin: 1rem` (16px), `gutter: 0.75rem` (12px). Full fluid width for cards and proof blocks with horizontal sliding data tables.

### Rhythm and Spacing Strategy
- **Micro Spacing (`space-xs` = 4px, `space-sm` = 8px):** Applied to tag interiors, monospaced hash chip padding, status indicator dots, and inline validation markers.
- **Component Spacing (`space-md` = 16px, `space-lg` = 24px):** Form field gaps, card body paddings, segmented button rails, and cryptographic tree node connectors.
- **Structural Spacing (`space-xl` = 40px):** Major dashboard sectional blocks, proof inspector separations, and ledger timelines.

## Elevation & Depth

Visual hierarchy does not use arbitrary high-drop drop shadows. Instead, it relies on **Luminescent Layering, Tonal Stacking, and Precision Edge Refraction**.

### Surface Depth Architecture
- **Layer 0 (Canvas Base):** Solid `#000B0F`. Non-elevated, baseline foundation.
- **Layer 1 (Card Bedrock):** `#00171F` background, bounded by a 1px solid border composed of `#003459`. Zero outer shadow.
- **Layer 2 (Elevated Nodes & Focus States):** `#00171F` with a soft inner radial gradient highlight (`rgba(0, 168, 232, 0.04)`) and a 1px border colored `#007EA7`. Outer drop glow: `0 4px 20px rgba(0, 126, 167, 0.15)`.
- **Layer 3 (Modals, Context Overlays & Drawers):** Backdrop-filter `blur(16px)` with surface `#00171F` at 85% opacity, framed by a 1px border of `#00A8E8` at 40% opacity. Casts a dark diffuse shadow: `0 16px 40px rgba(0, 5, 8, 0.8)` layered with a subtle neon bleed: `0 0 32px rgba(0, 168, 232, 0.08)`.

### Border & Highlight Logic
- Cards and panels utilize a hairline top-edge accent line via CSS pseudo-elements: a 1px horizontal gradient running from transparent to `#00A8E8` (30% opacity) to transparent, establishing directional top lighting.

## Shapes

The design system employs a disciplined, micro-radiused geometry (Level 1 - Soft) to reinforce the precision of high-security institutional engineering.

### Corner Radius System
- **Base Components (Inputs, Buttons, Pills, Data Cells):** `0.25rem` (4px). Provides engineered crispness while avoiding raw brutalist corners.
- **Containers & Surface Cards (`rounded-lg`):** `0.5rem` (8px). Used for ledger cards, transaction panels, code blocks, and data tables.
- **Modals & Drawers (`rounded-xl`):** `0.75rem` (12px). Softened slightly to anchor larger surface areas against deep backgrounds.
- **Pills / Status Chips:** Special case radius of `9999px` strictly reserved for atomic boolean status indicators (e.g., `VALIDATED`, `TAMPER DETECTED`, `REVOKED`).

## Components

### Buttons & Interactive Triggers
- **Primary Action (Commit / Sign / Validate):** Surface `#007EA7`, text `#FFFFFF`, 4px border radius. On hover: background `#00A8E8`, box-shadow `0 0 16px rgba(0, 168, 232, 0.45)`. On active: subtle scale down (98%).
- **Secondary (Inspect / Export):** Surface transparent, 1px border `#003459`, text `#D4DEE2`. On hover: surface `#00171F`, border `#007EA7`, text `#00A8E8`.
- **Destructive (Revoke Proof / Purge):** Surface transparent, 1px border `rgba(217, 56, 56, 0.4)`, text `#D93838`. On hover: background `rgba(217, 56, 56, 0.12)`, border `#D93838`, box-shadow `0 0 14px rgba(217, 56, 56, 0.3)`.

### Chips & Cryptographic Data Badges
- **Attribution Badges:** Background `rgba(0, 126, 167, 0.12)`, text `#007EA7`, 1px border `rgba(0, 126, 167, 0.3)`. Strict standard: Attribution must never be assigned green.
- **Integrity Verified Badge:** Background `rgba(30, 143, 83, 0.12)`, text `#1E8F53`, 1px border `rgba(30, 143, 83, 0.3)`. Contains a 6px glowing green status pip.
- **Tamper Alert Badge:** Background `rgba(219, 56, 56, 0.12)`, text `#D93838`, 1px border `rgba(219, 56, 56, 0.35)`. Contains an alert iconography marker.

### Input Fields & Key Entry
- **Default State:** Background `#00171F`, 1px border `#003459`, text `#FFFFFF`, typography `JetBrains Mono` 13px. Placeholder in `#66747A`.
- **Focus State:** Border `#00A8E8`, box-shadow `0 0 0 1px #00A8E8, 0 0 12px rgba(0, 168, 232, 0.25)`, outline: none.
- **Copyable Hash Field:** Integrated inline one-click copy icon button on trailing edge with instantaneous tooltip verification feedback ("Hash Copied").

### Cards & Ledger Blocks
- Background `#00171F`, border 1px solid `#003459`, padding `1.5rem`.
- Divided inside using subtle hairlines: 1px border of `#D4DEE2` at 12% opacity.
- Hover state on interactive ledger blocks raises border tint to `#007EA7` with a cyan atmospheric edge glow.

### Checkboxes & Toggle Controls
- Box size 16px × 16px, background `#000B0F`, 1px border `#003459`, radius 3px.
- Checked state: background `#007EA7`, border `#00A8E8`, check icon in `#FFFFFF`.

### Specialized Domain Components
- **Merkle Proof Tree Visualizer:** Nodes encased in `#00171F` with 1px border `#003459`. Connected via 1px vectors in `#007EA7`. Active path nodes pulsed with `#00A8E8`.
- **Creator Proof Signature Stamp:** Double-bordered certification panel with timestamp in `mono-data-sm`, cryptographic signature fingerprint in `mono-data-md`, and watermarked micro-seal in `#007EA7`.
